Approach: This pipeline is designed for secure, offline extraction utilizing LangChain and a local LLM via Ollama. By pairing a zero-temperature LLM with PydanticOutputParser, the architecture strictly coerces the unstructured text into a validated JSON schema. pdfplumber is utilized for upstream text ingestion due to its precision with structural PDF elements. I opted for local inference to demonstrate how to handle sensitive construction documents without relying on costly, external API calls.
Failure Modes (Where this breaks in production):
OCR Degradation: Heavily scanned PDFs with handwritten annotations (e.g., a scribbled cost adjustment) will result in garbage text. The LLM might confidently extract a hallucinated figure if the upstream OCR fails to capture the true characters.
Context Window Overload: For massive 50+ page change orders bundled with architectural drawings, passing the entire raw text will cause the LLM to lose focus on the middle context. This would require an intermediate chunking or retrieval (RAG) step prior to extraction.
Semantic Confidence vs. Statistical Confidence: LLMs are poor self-evaluators. A confidence score of 0.9 generated by the model represents semantic certainty, not a statistical probability. It is prone to overconfidence on hallucinated values if the prompt is not strictly bounded.
